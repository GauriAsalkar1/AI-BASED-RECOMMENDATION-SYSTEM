DESCRIPTION OF THE TASK: The movie recommendation system project is a Java-based application that leverages Apache Mahout's machine learning libraries to provide personalized movie suggestions to users. The system implements collaborative filtering techniques, specifically both user-based and item-based recommendation approaches, to analyze patterns in user ratings and generate meaningful predictions about which movies a particular user might enjoy. The core functionality revolves around processing user-movie rating data, calculating similarity metrics between users and items, and producing ranked lists of recommended films based on these calculations. The project begins with setting up the necessary infrastructure, including the Maven build system and its wrapper, which ensures consistent builds across different environments. Maven handles dependency management, automatically downloading required libraries like Mahout logging. The project structure follows standard Maven conventions, with source code organized under src/main/java and resource files like movie data stored in src/main/resources. This organization makes the project maintainable and easy to understand, separating configuration from implementation logic. At the heart of the system lies the data model, which consists of two key CSV files: movie_titles.csv and movie_ratings.csv. The titles file maps unique numerical identifiers to movie names, while the ratings file contains user-movie interaction data in the form of user IDs, movie IDs, and rating scores. These files are parsed and loaded into Mahout's FileDataModel, which provides efficient storage and access methods for the recommendation algorithms. The data model serves as the foundation for all subsequent analysis, making its structure and content critical to the system's accuracy. The recommendation engine implements two complementary approaches to generate suggestions. User-based collaborative filtering identifies users with similar rating patterns to the target user and recommends movies those similar users enjoyed. This method works by calculating Pearson correlation coefficients between users' rating vectors to determine similarity. Item-based collaborative filtering instead examines relationships between movies, recommending items similar to those the user has already rated highly. This approach often proves more stable for large-scale systems, as item similarities tend to change less frequently than user preferences. Both methods use Mahout's built-in implementations of these algorithms, including the PearsonCorrelationSimilarity class for calculating similarity scores and the GenericUserBasedRecommender/GenericItemBasedRecommender classes for generating predictions. The system outputs two ordered lists of recommendations: one from each algorithmic approach. Each recommendation includes the movie title and a predicted rating score, formatted to two decimal places for consistency. These scores represent the system's confidence that the user will enjoy each suggested movie, with values typically ranging from 3.0 to 5.0 in the sample output. The clean, numbered presentation makes the results easy to interpret while the inclusion of both recommendation strategies allows for comparison of different approaches. Implementation challenges included proper path handling for resource files in Windows environments, Java version compatibility issues, and tuning Mahout's neighborhood size parameters for optimal results. The solution addresses these through absolute path specifications in the Java code, explicit Java version targeting in the Maven configuration, and empirical testing of neighborhood sizes. The final system demonstrates core principles of recommendation systems, including similarity computation, prediction generation, and result evaluation, while maintaining straightforward operation through Maven build commands. This project serves as both a functional recommendation tool and an educational demonstration of fundamental machine learning concepts applied to real-world preference data. The architecture could be extended with additional features like genre filtering, hybrid recommendation strategies, or integration with larger movie databases, while the core implementation provides a solid foundation for understanding collaborative filtering techniques in Java-based systems. The inclusion of sample data and Maven wrapper files makes the project immediately executable, while the clean separation of components facilitates modification and experimentation with different algorithms or datasets.
